# 🚀 OnikaAnime

Космический портал в мир аниме.

## ✨ Особенности

- 🎬 Каталог аниме через Shikimori API (GraphQL + REST)
- 🔍 Поиск с автодополнением
- 💬 Комментарии к аниме
- ❤️ Избранное с массовым выделением
- 🏆 Система достижений с редкостями (common / rare / epic / legendary)
- 🎖️ Титулы за достижения
- 📊 Топ пользователей по XP
- 📺 Просмотр через VK Video / DEEP Entertainment / Kodi
- 🎲 Случайное аниме
- 👤 Профиль с аватаром, био, XP и уровнем
- 📱 Адаптивный неоновый дизайн

## 🛠️ Технологии

- **Frontend:** Vanilla JS, CSS3, HTML5
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **Security:** bcrypt, Joi
- **API:** Shikimori GraphQL + REST (через прокси)

## 📦 Установка

```bash
# Клонирование репозитория
git clone https://github.com/yourname/onika-anime.git
cd onika-anime

# Установка зависимостей
npm install

# Настройка .env файла
cp .env.example .env
# Отредактируйте .env с вашими данными PostgreSQL

# Запуск
npm start
