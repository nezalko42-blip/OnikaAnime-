# 🚀 OnikaAnime

Космический портал в мир аниме.

## ✨ Особенности

- 🎬 Просмотр аниме с Anilibria и Shikimori
- 🔍 Поиск и фильтрация по жанрам
- 💬 Комментарии
- ❤️ Избранное
- 🏆 Система достижений и титулов
- 👥 Друзья и чат
- 📊 Топ пользователей
- 📅 Расписание выхода
- 🎲 Случайное аниме
- 📱 Адаптивный дизайн

## 🛠️ Технологии

- **Frontend:** Vanilla JS, CSS3, HTML5
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **Security:** bcrypt, Joi

## 📦 Установка

```bash
# Клонирование репозитория
git clone https://github.com/yourname/onika-anime.git
cd onika-anime

# Установка зависимостей
npm install

# Настройка .env файла
cp .env.example .env
# Отредактируйте .env с вашими данными PostgreSQL

# Запуск
npm start
